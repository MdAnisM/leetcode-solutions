## Problem: Reverse a String (Easy)

**Link:** https://leetcode.com/problems/reverse-string/

### Approach

I used a two-pointer approach to reverse the string. One pointer starts from the beginning and the other starts from the end. The characters are swapped while the two pointers move toward the center.

### Complexity

- Time: O(n)
- Space: O(1)

### Notes

I learned that the string can be reversed without creating another array. I also tested the solution with a normal string and an edge case such as a single character.
